# HANDOFF — как продолжить GU World 2

Точка входа для следующей сессии Claude (или человека). Обновляется после каждого этапа.
**Сначала прочти этот файл целиком, потом `GDD.md`.**

## Что происходит

Игра переписана с нуля в ветке `gu-world-2` (старая игра — в `main`, не трогать).
Просьба автора: новый код, новый сюжет / прокачка / лут, играбельность, модель героя
`gu-hero.glb`, меньше «уродливых» моделей, оптимизация под слабый ноутбук **и** высокое качество
для других ПК, в конце — билд. Интерфейс v3 автору нравится: кит сохранён, экраны новые.

## Как запустить (автору)

1. `git fetch && git checkout gu-world-2`, открыть проект в Unity 6000.6.5f1.
2. Меню **Gu World → Check content** — в консоли должно быть «all … in place».
3. Меню **Gu World → Open the game's scene**, нажать Play. Сцена пустая: игра всё строит сама.
4. Билд: **Gu World → Build for Windows** или `Tools\V2\build.ps1` → `Builds\GuWorld2\GuWorld.exe`.

Качество (Лёгкое / Обычное / Высокое) — на титульном экране и в паузе. Высокое: полная модель
героя (626 тыс. треугольников), все деревья, дальние тени, MSAA ×4, SMAA, свечение.

## Как устроен код

```
Assets/GuWorld/Core/            GuWorld.Core — чистый C# без UnityEngine
  Defs.cs, State.cs             типы контента и сохранения
  Content/                      GuBook, Books (вещи, враги, лут, рецепты, лавки), Valley (карта), Story (квесты)
  Rules/                        Session*.cs (все правила), Cultivation.cs
Assets/GuWorld/Scripts/         GuWorld — Unity-слой
  Game.cs                       старт без сцены, начало / конец игры, сохранение, Quality
  Actors/                       Actor, Hero, Enemy, RigAnimator (свой проигрыватель клипов), Models
  World/                        Ground (рельеф), Scenery, Thing, Npc, Spawns, CameraRig, Atmosphere
  Fx/Effects.cs                 снаряды, телеграфы ударов, вспышки, лут
  UI/Ui*.cs                     HUD и страницы; UI/Kit/ — кит v3 (не переписывать)
  Compat/                       три компонента, на которые ссылаются префабы Resources/Build
Assets/GuWorld/Editor/          GuWorldBuild: сцена, проверка контента, билд
Assets/GuWorld/Resources/       Models, Anim (*.bytes), Looks (перекраски), Build (префабы домов),
                                Terrain (слои), Mats, Shaders, Fonts
Tools/V2/                       check.sh, Sim (тесты и бот), UnityCheck + stubs (компиляция),
                                models/ (hero.py, anim.py, canid.py — Blender как модуль), build.ps1
```

Принцип: всё, что считается без движка, живёт в `Core` и проверяется `Sim`. Unity-слой только
показывает и управляет. Мир не хранится в сцене — строится при старте из `Core/Content/Valley.cs`.

## Проверки (в облаке, без Unity)

```
bash Tools/V2/check.sh          # всё
bash Tools/V2/check.sh core     # правила, контент, прохождение ботом, баланс
bash Tools/V2/check.sh unity    # компиляция Unity-слоя
```

Нужно: .NET SDK 8 (`curl -sSL https://dot.net/v1/dotnet-install.sh | bash -s -- --channel 8.0 --install-dir /opt/dotnet`).
`UnityEngine.Modules` 2021.3.33 ставится из NuGet сам. Заглушки в `Tools/V2/stubs/` — только
используемое API; при новой ошибке «нет такого члена» сначала убедиться, что он есть в настоящем
пакете, потом добавить в заглушку. Проверка честная: подставленная ошибка в теле метода ловится.

Модели: `pip install bpy pillow numpy fonttools`, затем из `Tools/V2/models/`:
`python hero.py` (LOD-модели и перекраски), `python anim.py` (анимации людей; `anim.py sheet out.png`
— лист поз), `python canid.py Fox.glb` (волки). Формат анимаций — в `gwa.py`.

Шрифты печатей — подмножества (215 иероглифов, упрощённые). Новые печати брать из тех, что в
шрифте: `Gu World → Check content` пишет, каких глифов нет.
