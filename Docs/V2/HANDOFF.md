# HANDOFF — как продолжить GU World 2

Этот файл — точка входа для следующей сессии Claude (или человека). Обновляется после
каждого этапа. **Сначала прочти его целиком, потом `GDD.md`.**

## Что происходит

Игра переписывается с нуля в ветке `gu-world-2` (старая игра — в `main`, не трогать).
Просьба автора: новый код, новый сюжет / прокачка / лут, играбельность, модель героя
`gu-hero.glb` (из ветки `gu-hero-model`), меньше «уродливых» моделей. UI v3 автору нравится —
кит интерфейса сохранён.

## Правила работы

- Работать только в `gu-world-2`, коммитить и пушить после каждого законченного куска.
- Unity в облачной сессии нет. Проверка: `Tools/V2/check.sh` (см. ниже). Автор запускает игру
  у себя (Unity 6000.6.5f1, Windows, Iris Xe — без дискретной видеокарты, беречь кадры).
- Код и комментарии — по-английски, тексты игры — по-русски.
- После каждого этапа обновлять раздел «Состояние» ниже.

## Как устроен код

```
Assets/GuWorld/Core/      GuWorld.Core — чистый C# без UnityEngine: правила и контент
Assets/GuWorld/Scripts/   GuWorld — Unity-слой (мир, герой, бой, ИИ, интерфейс)
Assets/GuWorld/Editor/    сборка, сцена, дым-тест
Tools/V2/                 проверки (dotnet) и подготовка моделей (bpy)
Docs/V2/                  GDD.md, HANDOFF.md
```

Принцип: всё, что можно посчитать без движка (урон, лут, квесты, слияние, сохранение), живёт
в `Core` и проверяется тестами и прогоном сюжета ботом. Unity-слой только показывает и
управляет.

## Проверки

```
bash Tools/V2/check.sh          # всё сразу
bash Tools/V2/check.sh core     # тесты ядра + прогон сюжета
bash Tools/V2/check.sh unity    # компиляция Unity-слоя против сборок-заглушек
```

Нужны: .NET SDK 8 (`dotnet-install.sh --channel 8.0`), пакет NuGet `UnityEngine.Modules`
2021.3.33 (ставится сам). UGUI / Input System / URP в NuGet нет — для них рукописные заглушки в
`Tools/V2/stubs/` (только то API, что используется; расширять по ошибкам компиляции).
Версия заглушек старее Unity 6: не использовать API, которого нет в 2021.3, без нужды
(`Rigidbody.linearVelocity` и т.п.); герои и враги ходят на `CharacterController`.

Модели: `pip install bpy` (Blender как модуль Python 3.13), скрипты в `Tools/V2/models/`.
