# Генераторы GU World — что есть и куда расти

Ветка `generators` (от `gu-world-2`). **Сначала прочти этот файл, потом `HANDOFF.md`.**

Просмотрщик (артефакт): https://claude.ai/artifact/HGL32rxizqtu4k58ADFn6s — деревья с текстурами,
уровни детализации, параметры; участки биомов. Исходник — `Tools/V2/viewer/index.html`.

2. **Люди.** Сгенерированные с нуля человечки отвергнуты («уродские»). Правильный путь: взять
   готовую модель героя `gu-hero.glb` и её риг, доработать их и сделать из неё **общий шаблон**,
   а из шаблона — группы:
   - клан **Гу Юэ** (свои особенности, одежда);
   - клан **Сюн** (медвежьи одежды; цвет кожи другой из-за места жительства);
   - клан **Бай** (белая одежда);
   - жители мелких деревень;
   - одинокие культиваторы;
   - демонические и другие.
   → Не начато. Старый генератор (`Core/Gen/People`) выключен: `People.Enabled = false`, в игре
   снова стоит прежняя модель с перекраской. Код оставлен только ради скелета и скиннинга.

## Деревья: как устроено

```
Core/Gen/Flora/
  TreeSpecies.cs   вид дерева как набор чисел (все поля описаны в коде) — 11 видов
  TreeGen.cs       выращивание дерева из вида, зерна и TreeParams
  TreeLibrary.cs   варианты на вид (простор/чаща × прямо/наклон/сильный наклон × зёрна) для леса
  Biomes.cs        профили биомов и поля мира (величие, ветер, граница леса)
  Build.cs         общие кирпичи (трубки, комки, ленты)
Tools/V2/models/
  treetex.py       рисует текстуры → Assets/GuWorld/Resources/Trees (кора 2048² + карта высот, мох, 13 атласов листвы)
  treeshots.py     рендер деревьев в Blender (как в игре: кора + мох по весу вершин, листва с альфой)
Resources/Shaders/ TreeBark (кора + мох, рельеф из карты высот без тангентов), TreeLeaf (вырез по альфе,
                   двусторонняя, ветер по альфе вершин, просвет), TreeGlow (светящийся мох)
Scripts/World/Forest.cs   лес: варианты растут в фоне по мере надобности, меш на уровень с сабмешем на
                          материал, инстансинг; у ближних деревьев MeshCollider (TreeSolid)
Scripts/Actors/Hero.cs    лазание (режим Climbing)
```

**Что растёт.** Ствол на контрфорсах, которые уходят в корни по земле; наросты; воротники в местах
выхода ветвей; ветви, по которым можно ходить; ветки и побеги. Кора — тайловая текстура вида;
в вершинах лежат вес мха (красный) и затенение (зелёный). Листва — карточки с нарисованными
ветками (подушки у сосны, лапы у пихты, занавеси у ивы), скрещённые и изогнутые. На дереве живут
трутовики, бороды лишайника, лианы с плющом, у древних — светящийся мох; сломанные верхушки и
сухие сучья. Четыре уровня детализации, меш столкновений и список ветвей для лазания.

**Виды и высоты:** сосна 28–62 м, пихта 32–75, кипарис 22–50, камфора 40–80, клён 18–40,
слива 6–14, ива 16–34, берёза 20–42, сухостой 15–45, древнее дерево 85–110, бамбук 10–24.

**Параметры генерации** (`TreeParams`, на каждое дерево): `Height` высота, `Lean` наклон,
`Crowding` теснота (простор → чаща), `Age` возраст (толщина, наросты, контрфорсы), `Season`
(осень/цветение), `Wet` влажность (мох, лишайник), `Foliage` густота листвы, `Decay` упадок
(сухие сучья, грибы). Параметры вида (`TreeSpecies`): обхват, сбег, контрфорсы, корни, форма
кроны, число и толщина ветвей, уровни ветвления, текстуры коры и листвы, размер веток листвы,
мох, лишайник, грибы, лианы и т. д. — около 40 чисел, все подписаны в коде.

**Числа (13.11.2026).** Древнее дерево 105 м: ствол 7 м в толщину, подножие с корнями ~30 м,
крона ~96 м, 203 ветви для лазания; ~370 тыс. треугольников вблизи, ~11 тыс. вдали, ~2 тыс. на
горизонте. В среднем по видам ~87 тыс. вблизи. Дерево растёт за ~0,1 с.

**Лазание.** Пробел, стоя лицом к коре (с земли или в прыжке), — герой хватается. Вперёд/назад —
вверх/вниз, влево/вправо — вокруг ствола, Shift — быстрее. Перелез на спину ветви или корня —
встал. Пробел на стволе — оттолкнуться. Клип `climb` добавлен в `anim.py`.

## Проверки (в облаке, без Unity)

```
cd Tools/V2/Sim
dotnet run -c Release -- gen                    # деревья, биомы: проверки + Logs/V2/gen/biomes.png
dotnet run -c Release -- gen export only=trees  # + .glb (4 уровня и _raw для Blender) в Logs/V2/gen/trees
cd ../models
python treetex.py                               # перерисовать текстуры в Resources/Trees (≈3 мин)
python treetex.py ../../../Logs/V2/gen/tex - ../../../Logs/V2/gen/tex   # копия для .glb + карты нормалей
python treeshots.py ../../../Logs/V2/gen out.png pine_1,ancient_2 wfcu  # рендер: целиком, подножие, крона, вид вверх
bash ../check.sh                                # всё остальное + компиляция Unity-слоя
```

Для чернового рендера биомов в Sim нужны маленькие копии текстур в `Logs/V2/gen/tex128/*.rgba`
(128×128 RGBA; без них деревья рисуются плоским цветом).

Картинки (`Docs/V2/gen/`): `trees-all.jpg` (все виды, красный столбик — человек 1,75 м),
`trees-close.jpg` (подножие, крона, вид вверх: сосна, камфора, древнее), `tree-textures.jpg`
(все текстуры), `biomes.png`, `biome-map.png`, эталон из игры — `trees-reference.jpg`.

**Что было плохо и как исправлено (13.11, вечер)** — чтобы не наступать второй раз:
- Мох лежал сплошным зелёным одеялом: формула покрытия в шейдере давала полное покрытие уже при
  весе 0,45. Теперь вес 0,5 = половина покрытия, рвётся высотами мха и коры (одна формула в
  `TreeBark.shader`, `treeshots.py`, `Raster.cs`).
- Контрфорсы шли «лесенкой»: гребень попадал между вершинами кольца. Теперь углы кольца ставятся
  по гребням и поворачиваются вместе с закруткой ствола (`TreeGen.Angles`).
- Кора `bark_broad` была в чёрных кляксах: расстояние до края ячейки Вороного в растянутой
  метрике в разы шире на концах ячеек. Теперь истинное расстояние (`edge_distance` в `treetex.py`);
  кора — переплетающиеся пробковые гребни с трещинами. `bark_dead` перерисована (серебристая
  древесина, усушечные трещины, сучки, остатки коры).
- Берёза была «брокколи» — крона облегчена, ветви свисают.

## Что проверить в Unity (агенту в VS Code) — ничего из этого в движке ещё не запускалось

1. Импорт: `Resources/Trees/*.jpg|png` (обычные текстуры, sRGB), три новых шейдера
   `Resources/Shaders/Tree*.shader`. Ошибки компиляции шейдеров — первым делом.
2. Лес: деревья видны, кора с текстурой и мхом, листва вырезана по альфе и качается. Если рельеф
   коры «вывернут» (свет снизу) — поменять знак `slope` в `TreeBark.shader`. Если листва чёрная
   или прямоугольниками — смотреть альфу текстур (`TreeLeaf`, `_Cutoff`).
3. Память и FPS: варианты тяжёлые. Число вариантов задаёт `new TreeLibrary(seeds)` в `Forest.Make`
   (1 зерно на «Лёгком» = 6 вариантов на вид), дальность уровней — `lodReach`.
4. Лазание: подойти к стволу, Пробел, вверх до первой ветви, пройти по ней. Герой не должен
   проваливаться в ствол и застревать на воротниках ветвей.
5. Герой стоит прямо (осанка), клип `climb` играет.
