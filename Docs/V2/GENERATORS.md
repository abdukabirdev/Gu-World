# Генераторы GU World — что есть и куда расти

Ветка `generators` (от `gu-world-2`). Задача автора от 12.11.2026: NPC не должны быть одинаковыми,
деревья — не копии одной модели, биомы с параметрами (где-то деревья выше), горбатый риг героя
переделать; тестовые артефакты для генераторов; всё записать в git, чтобы работать над каждым
месяцами. **Сначала прочти этот файл, потом `HANDOFF.md`.**

Просмотрщик (артефакт): https://claude.ai/artifact/HGL32rxizqtu4k58ADFn6s — деревья (уровни
детализации), люди (позы через скин), биомы. Исходник — `Tools/V2/viewer/index.html`; модели для
него пишет `Sim gen export` в `Logs/V2/gen/`.

## Как устроено

Всё, что генерирует, — чистый C# в `Assets/GuWorld/Core/Gen/` (без UnityEngine): одинаковый код
работает в игре и в облачных проверках. Одинаковое зерно → одинаковый результат.

```
Core/Gen/Flora/
  Build.cs         трубки по пути, комки листвы, ленты, повороты — общие кирпичи
  TreeSpecies.cs   11 видов деревьев как наборы чисел (сосна, пихта, кипарис, камфора, клён,
                   слива, ива, берёза, сухостой, древнее дерево, бамбук)
  TreeGen.cs       выращивание: ствол → ветви (спираль/мутовки, длина по форме кроны) → побеги →
                   листва (комки, подушки хвои, лапы, чешуя, цветы, свисающие пряди, бамбук);
                   корни, обломанные верхушки, мох, кора; 4 уровня детализации
  TreeLibrary.cs   варианты на вид (простор/чаща × прямо/наклон/сильный наклон × зёрна);
                   дерево карты берёт ближайший вариант, поворачивается наклоном по ветру, масштаб по росту
  Biomes.cs        профиль каждого биома (виды и доли, плотность, рост, теснота, ветер, возраст,
                   пятнистость, сезон, подлесок) + поля мира Woods: величие (рощи великанов до ×1.5),
                   ветер (направление плывёт по карте, сильнее наверху), граница леса, наклон по склону
Core/Gen/Scatter.cs   расстановка по клеткам 64 м из профилей биомов
Core/Gen/Surface.cs   биомы на карте (+ пихтовый пояс, кленовые рощи)
Core/Gen/People/
  Skeleton.cs      скелет героя (125 костей) — пишет Tools/V2/models/skeleton.py, руками не править
  Person.cs        PersonSpec (пол, возраст, ремесло, клан, достаток, зерно) и PersonModel
  PersonGen.cs     пропорции тела на скелете, скиннинг (4 ближайшие кости), лофты
  PersonParts.cs   тело, шея, голова и лицо, волосы (11 причёсок), бороды, руки, ноги
  PersonClothes.cs одежда: штаны, халат/туника/куртка/безрукавка, воротник «левое на правое»,
                   рукава, юбка халата на костях юбки, пояс, фартук, доспех, корзина, шляпы
  Outfits.cs       что носит кто: палитры кланов, ремёсел и достатка, узоры, грязь
```

В игре:

- `Scripts/World/Forest.cs` — все деревья инстансами по (вариант, уровень детализации); объекты
  только для коллайдеров стволов и валунов; библиотека растёт в фоновом потоке после загрузки.
- `Scripts/Actors/People.cs` — скелет + SkinnedMeshRenderer из PersonModel, анимации героя
  играют на любом теле. `Models.Human` делает так всех, кроме героя и каменной статуи
  (`People.Enabled = false` вернёт старую модель). Горожане — у каждого свой человек
  (`walker.Id`), новых не больше 6 за круг, неактивных тел держим ≤ 40.
- `Tools/V2/models/anim.py` — POSTURE: исправление сутулости в каждой позе (`Docs/V2/rig-posture.png`).

## Проверки (в облаке, без Unity)

```
cd Tools/V2/Sim
dotnet run -c Release -- gen                 # деревья, биомы, люди: проверки + картинки в Logs/V2/gen
dotnet run -c Release -- gen export          # + .glb и .json для просмотрщика
dotnet run -c Release -- gen only=people     # только люди (trees, biomes, people)
bash Tools/V2/check.sh                       # всё остальное + компиляция Unity-слоя
```

Картинки последнего прогона лежат в `Docs/V2/gen/`: `trees.png`, `biomes.png`, `biome-map.png`,
`people.png` (спереди, сзади, в позе через скин), `faces.png`.

Числа на 13.11.2026: дерево растёт за ~3 мс (все 4 уровня), LOD0 10–40 тыс. треугольников, LOD3 20–500;
человек ~5 мс, ~7 тыс. треугольников; 63 разных наряда/причёски на 72 человека.

## Что проверить в Unity (агенту в VS Code)

1. Компиляция (новые файлы: Core/Gen/Flora, Core/Gen/People, Actors/People.cs, новый Forest.cs).
2. Лес: деревья видны, не чёрные и не вывернуты (шейдер VertexLit), качаются слегка; стволы
   твёрдые; FPS на «Обычном» не ниже прежнего. В логе автотеста строка `… trees and shapes drawn`.
3. Люди: горожане разные, стоят на ногах, анимации ходьбы/покоя играют, не «взрываются»
   (если тела смотрят назад или скручены — смотреть `People.Make`: поворот костей
   `(Qx, −Qy, −Qz, Qw)` и `RigAnimator.Mirrored`). Внутренности рукавов видны (материал двусторонний).
4. Герой: стоит прямо, голова над плечами (новые анимации).

## Дорожная карта (на месяцы)

### Люди
- [ ] Текстуры вместо одних вершинных цветов: генерируемый атлас ткани (узоры, вышивка, заплаты в пикселях), карта лица.
- [ ] Лицо: больше вершин на лице, веки, губы формой, морщины у старых; выражения (кости лица героя уже есть).
- [ ] Руки с пальцами (кости пальцев есть, сейчас «варежка»).
- [ ] Больше одежды: плащи, накидки, длинные женские юбки с запахом, пояса с подвесками, обувь разных видов, украшения.
- [ ] Волосы: пряди лентами, чёлки; пружинные кости для хвостов и рукавов (SpringBones уже умеет).
- [ ] LOD людей (сейчас один уровень ~7 тыс.), импосторы толпы вдали.
- [ ] Фоновая генерация людей в потоке (сейчас на главном, по 6 за круг).
- [ ] Именованным NPC — заданные вручную PersonSpec (внешность из лора), генерация только для массовки.

### Деревья
- [ ] Листья карточками с альфа-текстурой (ближний LOD), сейчас — комки.
- [ ] Ветер по ветвям (вершинный цвет = вес качания), а не по высоте целиком.
- [ ] Сезоны: весна/осень/зима для всех видов (поле `Season` уже есть).
- [ ] Импосторы для LOD3 (рисованные спрайты с 8 сторон) — ещё легче даль.
- [ ] Новые виды: гинкго, баньян, тис, туя, кусты (рододендрон, чай), упавшие стволы, пни.
