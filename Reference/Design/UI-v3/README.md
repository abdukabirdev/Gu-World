# GU World — интерфейс v3 · «Обряд × Апертура»

Исходники макетов с холста Claude Design. Положите папку в репозиторий как `Design/UI-v3/` и попросите Claude Code реализовать экраны по ней в `Assets/GuWorld/Scripts/UI` (`UiKit.cs`, `MenuSkin.cs`, `Menus*.cs`).

Каждый `*.dc.html` — один экран 1440 × 900. Это HTML с inline-стилями и небольшим JS-классом (`renderVals()`) с данными. Сам по себе в браузере не откроется (нужен рантайм холста), но как спецификация читается полностью: размеры, цвета, шрифты, тексты и анимации лежат прямо в разметке и в `<style>` внутри `<helmet>`.

`GU-World-Экраны.xlsx` — таблица экранов: файл, содержимое, исходник в коде, клавиша, что заменить реальными данными, статус переноса в Unity.

## Формы и поведение

- Главная кнопка — вытянутый шестиугольник (`clip-path: polygon(20px 0, calc(100% - 20px) 0, 100% 50%, …)`), золотая кромка 1 px, тёмное или золотое тело.
- Опасное и необратимое (слияние, сброс игры) — только удержанием: кнопка заполняется слева направо, около 1,2 с.
- Выбранная строка списка — золотой ромб слева, градиент золота к прозрачному, тонкие линии сверху и снизу.
- Ячейка предмета — восьмиугольник 72 px, полоска цвета ранга снизу.
- Клавиши-подсказки — «кейкапы» рядом с каждым действием и строка подсказок внизу экрана.
- Движение: парение 6 с, пульс свечения 5 с, кольца вращаются за 30–160 с, окно появляется за 0,4 с с масштаба 0,92.

## Важно

Цифры в макетах (цены, проценты, урон по частям тела, ранги в кодексе), иероглифы-имена Гу и названия команд чата — примеры. Места для реальных данных отмечены `[...]`. Реальные значения берутся из `GuBook`, `ItemBook`, `Commands` и `Talents`.
